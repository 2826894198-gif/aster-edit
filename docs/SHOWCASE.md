# Aster Edit · 生活方式电商品牌 · 项目展示

## 一句话介绍

让一个商品系列，拥有从品牌故事到完整购买页的英文电商体验。

## 项目价值

以商品事实和真实素材为基础，把系列故事、完整商品页、响应式图片与购买入口组织成协调的英文电商体验，并保留可追溯的发布与回退证据。

## 最值得展示的能力

- 系列、搜索、Shop 与商品详情旅程
- Prism 十二星座选择、比较联动与上下文购买条
- Vertex 八个稳定 SKU、购物袋与直接购买映射
